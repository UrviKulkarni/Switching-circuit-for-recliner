# Switching-circuit-for-recliner
This is a simulation to show the working of a recliner only when a minimum required weight is placed on it. 
Designing a c program that accurately represents the working of an switch like on/ off states, switching dynamics and its impact on the system behaviour. The program should interpret input values and give the expected outcome. It should also be able to detect invalid input values and provide required error message accordingly. The user should be able to analyze system behaviour, predict system behaviour and develop control logic smoothly using this program.

ii)  Algorithm: 
Steps 
1.Start
2.Input weight and time as wt and t respectively
3.Set wt > (min req wt) and t=(desired time)
4.Display reclined chair if both the conditions are satisfied
5.End
